# Modality Concept

## 1. What Is a Modality?

In Machine Learning and Deep Learning, a **modality** refers to the **form or type of data processed by a model**.

Even when observing the same object or phenomenon, data can be considered different modalities if it is represented or measured in different ways.

Representative modalities include the following.

```text
Real-world object or phenomenon
        │
        ├── Photo or video             → Image Modality
        ├── Sentence or document       → Text Modality
        ├── Voice or sound             → Audio Modality
        └── Measurements over time     → Time-series Modality
```

For example, in a model that analyzes a person's condition, a facial image can be treated as an Image Modality, a sentence describing symptoms as a Text Modality, voice as an Audio Modality, and measurements such as heart rate collected over time as a Time-series Modality.

---

## 2. Difference Between Modality and Features

Modality and features are different concepts.

- **Modality** is the form or type of data provided as model input.
- **Features** are representations extracted or learned by an encoder from the input of that modality.

```text
Modality                 Encoder                 Features

Image       ─────→    Image Encoder    ─────→ Image Features
Text        ─────→    Text Encoder     ─────→ Text Features
Audio       ─────→    Audio Encoder    ─────→ Audio Features
Time-series ─────→ Time-series Encoder ─────→ Time-series Features
```

Therefore, an Image itself is not the same as Image Features. Image is an input data modality, while Image Features are feature representations generated by an Image Encoder from an Image input.

These features can be described as **modality-specific features**.

---

## 3. Single Modality and Multiple Modalities

A model that uses only one modality can be considered a single-modality model.

```text
Image
  ↓
Image Encoder
  ↓
Image Features
  ↓
Prediction
```

When two or more different modalities are used for a single target task, Multimodal Learning can be applied.

```text
Image ───────→ Image Encoder ───────→ Image Features ───────┐
                                                            │
Text ────────→ Text Encoder ────────→ Text Features ────────┼→ Interaction → Prediction
                                                            │
Time-series ─→ Time-series Encoder ─→ Time-series Features ─┘
```

The mere existence of multiple types of data does not mean that Multimodal Learning should be applied. It is necessary to determine whether each modality-specific feature is required for the target task and to verify whether using multiple modalities actually improves model performance.

---

## 4. Modality and Interaction

Using different modalities in Multimodal Learning does not automatically mean that relationships between modalities are learned.

Each modality encoder can first generate modality-specific features, and when relationships between different modality-specific features need to be learned, a separate Interaction mechanism can be applied.

```text
Image Modality
      ↓
Image Encoder
      ↓
Image Features ──────────┐
                         │
                         ├→ Interaction → Prediction
                         │
Text Features ───────────┘
      ↑
Text Encoder
      ↑
Text Modality
```

Interaction mechanisms may include Attention, Cross-Attention, Gating, Similarity, Feature Selection, and other methods.

Attention is not itself a modality. Attention is a mechanism for computing relationships and relevance between features or representations.

---

## 5. Transformer Attention and Modality

Transformer Self-Attention can be used to compute relationships among elements within the same representation sequence.

For example, a Text Transformer can compute relationships among token representations.

```text
Text Modality
     ↓
Token Representations
     ↓
Self-Attention
     ↓
Text Features
```

In multimodal models, mechanisms such as Cross-Attention can be used to compute relationships between different modality-specific features.

```text
Text Features  → Query
Image Features → Key
Image Features → Value
        │
        ↓
Cross-Attention
        │
        ↓
Cross-modal Interaction Features
```

Therefore, it is important to distinguish that **Attention is a mechanism for computing relationships, while Modality is the form or type of data processed by the model**.

---

## 6. Modality in Infinite Union

Infinite Union treats maintaining the identity and independence of each modality and its modality-specific features as a fundamental principle.

```text
Image       → Image Encoder       → Image Features
Text        → Text Encoder        → Text Features
Audio       → Audio Encoder       → Audio Features
Time-series → Time-series Encoder → Time-series Features
                                      │
                                      ↓
                                Features Union
```

Even when multiple modality-specific features are included in a Features Union, it should remain possible to identify the modality from which each feature was generated and to access each feature independently.

When necessary, an Interaction component selects specific modality-specific features from the Features Union, connects them, and computes their relationships.

Through this approach, Infinite Union aims to construct a **modeling methodology in which each feature preserves its independence while being connected and interacting with others, and in which new modalities and features can continue to be extended**.
